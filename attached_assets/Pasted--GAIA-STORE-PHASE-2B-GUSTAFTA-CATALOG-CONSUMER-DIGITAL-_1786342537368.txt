## 3. GUSTAFTA CATALOG API

==================================================

GAIA harus membaca katalog dari:

https://<DOMAIN-GUSTAFTA>/api/v1/catalog

JANGAN hard-code production domain jika domain belum tersedia.

Gunakan environment variable:

GUSTAFTA_CATALOG_BASE_URL

Contoh:

GUSTAFTA_CATALOG_BASE_URL=https://gustafta.my.id/api/v1/catalog

Sesuaikan dengan domain production sebenarnya.
